# Daniel Anderson de Souza Silva

**Master's student in Computer Science — UFCG** · Agentic Software Engineering

I study how LLM agents decompose monoliths into microservices — and how to verify
that the architecture they produce is internally coherent when there is no
reference answer to compare against.

### What I'm building

| Project | What it does |
|---|---|
| [DAVINCI](https://github.com/DanielAndersonTI/DAVINCI) | Five-agent pipeline that turns a monolith's user stories into a microservice decomposition. Empirical protocol: 8 systems × 5 agent configurations × 3 LLMs × 3 rounds at temperature 0.0. |
| [Evaluation Framework](https://github.com/DanielAndersonTI/LLM-Based-Microservice-Decomposition-Evaluation-Framework) | Structural adherence metrics between a generated architecture and the source monolith. |
| [Experiment-Agents-Tests](https://github.com/DanielAndersonTI/Experiment-Agents-Tests) | Reproducibility protocol for agent-based code generation experiments. |
